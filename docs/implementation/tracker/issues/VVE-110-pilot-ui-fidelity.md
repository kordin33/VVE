# Pilot UI fidelity

## Outcome

Administrator, Teacher, Student entry, and lesson surfaces form one coherent tactile family while preserving working area, direct manipulation, readability, and iPad behavior.

## Context pointer

Implement section `S10 - Pilot UI Fidelity` in [VVE Deep Module Design](../../../architecture/VVE-DEEP-MODULE-DESIGN.md). Use `neumorphic-design` as the visual language, `apple-design` for Apple-faithful interaction and verification, and `motion` for the final motion verdict.
